Scripts used in marmot methylation snowmelt manuscript.

1. Shell scripts to analyze EMseq data with MspI digest (RR-EMseq, NEB kit version 1)
2. R script to produce filtered methylation matrix
3. R script to assemble sample metadata
4. Python notebook for PCA
5. R script to run CpG binomial GLMMs
6. Shell commands to annotate genomic outliers
7. R script to profile promoter methylation
8. Python notebooks to assemble climate data
9. R script and handler to run biophysical models (Niche Mapper)
