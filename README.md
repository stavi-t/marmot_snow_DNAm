# Code used in Tennenbaum et al. 2026: 

Seasonal climate change shapes epigenetic and physiological regulators of metabolism in a hibernating mammal

## DNA methylation data

1. Shell scripts to analyze RR-EMseq data with MspI digest (NEB kit v1): trim, align, call methylation
2. Shell and python scripts to analyze control DNA: lambda and pUC19 align, call methylation, produce methylation matrix, summarize results
3. Python notebooks for PCA and sequencing depth
4. R scripts to assemble metadata and run binomial GLMMs in lme4-breeding: analyze variance, models and filter results
5. Shell commands to annotate genomic outliers in bedtools
6. R scripts for visualizing promoter methylation and GO/KEGG functional enrichment

## Microclimate data 

1. Python notebooks to assemble climate data
2. Python notebooks to visualize geospatial data

## Biophysical niche models

1. R scripts to run Niche Mapper and act as data handler
